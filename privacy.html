プライバシーポリシー

最終更新日: 2026年11月1日

本ポリシーは、動画シリーズ「株式会社どうぶつ商事」の運営者（以下「運営者」）が、 動画の投稿に使う自作ツール（以下「本ツール」）における情報の取り扱いを定めるものです。

1. 本ツールの目的

本ツールは、運営者が制作した動画を、運営者自身のYouTubeチャンネル等にアップロードするためだけに使用します。 第三者が利用するサービスとしては提供していません。

2. 取得する情報

本ツールは、YouTube API サービスを通じて、運営者自身のGoogleアカウントの次の権限のみを使用します。

  • YouTubeへの動画のアップロード（スコープ: youtube.upload）

認証のためのアクセストークンは運営者の管理する環境にのみ保存し、それ以外の個人情報は取得しません。

3. 情報の利用と共有

取得した情報は動画のアップロードのためだけに使用し、第三者への販売・提供・共有は行いません。 また、広告配信や機械学習モデルの学習には使用しません。

4. 情報の保存と削除

アクセストークンは、運営者がツールの利用をやめた時点で削除します。 Googleアカウントのサードパーティのアクセス設定から、いつでも権限を取り消すことができます。

5. 外部サービス

本ツールは YouTube API サービスを使用しています。YouTube の利用には YouTube 利用規約が、Google による情報の取り扱いには Google プライバシーポリシーが適用されます。 本ツールによる Google API から取得した情報の利用は、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。
